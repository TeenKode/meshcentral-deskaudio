# Changelog

## 0.1.1

* Windows 7 и старые системы: хелпер теперь собирается любым встроенным `csc.exe` — поиск по
  `v4.0.30319 → v3.5 → v2.0.50727` (обе разрядности). .NET 3.5 / 2.0 встроены в Windows 7 по умолчанию,
  так что .NET Framework 4 больше не обязателен. Исходник `win-loopback.cs` ограничен C# 2.0.

## 0.1.0

* Первая версия. Вкладка «Звук» на странице устройства: передача звука рабочего стола удалённого
  компьютера в браузер в реальном времени.
* Windows — WASAPI loopback (хелпер собирается на месте через `csc.exe` из .NET Framework 4).
* Linux — `parec` (PulseAudio / PipeWire) с монитора текущего устройства вывода.
* Требуется право «Удалённое управление» на устройство; каждое включение пишется в журнал событий.
