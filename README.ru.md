# Desktop Audio для MeshCentral

[English version](README.md)

Плагин для [MeshCentral](https://github.com/Ylianst/MeshCentral): в браузере слышно то, что играет на
динамиках удалённого компьютера, в реальном времени и вместе с удалённым рабочим столом.

* Работает на **Windows 7–11** (x86, x64, ARM64) и **Linux** (PulseAudio или PipeWire).
* По умолчанию звук в **Opus** (~32 кбит/с) на Windows; ADPCM на Linux и как запасной вариант.
* На удалённый компьютер ничего ставить не нужно: агент получает маленький хелпер захвата от вашего сервера.
* Одно устройство могут слушать несколько человек одновременно (или одна учётка с нескольких компьютеров).
* Соблюдает права и настройки согласия удалённого рабочего стола MeshCentral; каждый сеанс пишется в журнал.

## Требования

* MeshCentral 1.1.0 или новее с включёнными плагинами.
* Браузер с Web Audio: Chrome, Edge, Firefox или Safari. Для Opus нужен WebCodecs; без него плагин сам
  переключается на ADPCM.
* На Linux-устройствах: `parec` (`pulseaudio-utils`) или `pw-record` (`pipewire-bin`).
* macOS не поддерживается.

## Установка

1. Включите плагины в `meshcentral-data/config.json` и перезапустите MeshCentral:

   ```json
   "settings": { "plugins": { "enabled": true } }
   ```

2. В MeshCentral откройте **Мой сервер → Плагины → Загрузить плагин** и вставьте:

   ```
   https://raw.githubusercontent.com/TeenKode/meshcentral-deskaudio/main/config.json
   ```

3. Включите плагин в списке.
4. **Перезапустите MeshCentral.** Код плагина для агента попадает в ядро агента только при запуске сервера;
   агенты получают новое ядро при переподключении.

После каждого обновления плагина сервер тоже нужно перезапустить.

## Использование

* Откройте устройство: на вкладке **Звук** — кнопка «Слушать», громкость, настройки и журнал.
* На вкладке **Рабочий стол** кнопка **Звук** в панели включает и выключает прослушивание, не уходя с
  удалённого стола. При отключении рабочего стола звук тоже останавливается.
* Галочка *«Слушать звук при подключении к рабочему столу»* включает звук автоматически при каждом
  подключении.

Настройки на вкладке «Звук» запоминаются в браузере и применяются сразу:

| Настройка | Варианты |
| --- | --- |
| Кодек | Авто (Opus, если браузер умеет), Opus, ADPCM, PCM |
| Битрейт Opus | 24, 32, 48 кбит/с |
| Частота (ADPCM/PCM) | 8, 16, 24 кГц |
| Не передавать тишину | экономит трафик, пока ничего не играет |
| Буфер / задержка | низкий, средний, высокий |

Буфер подстраивается сам: если звук приходит с перерывами, он растёт (до 1 с), а при стабильной связи
уменьшается обратно. Подобранный размер запоминается для каждого устройства на сутки.

## Права и согласие

* Слушать может только пользователь с правом **«Удалённое управление»** на устройство. Пользователям с
  ограничением **«Нет рабочего стола»** звук недоступен.
* Если для группы устройств или пользователя требуется **согласие на рабочий стол**, на удалённом компьютере
  сначала спрашивают разрешение. При **уведомлении о рабочем столе** или **панели подключения** удалённый
  пользователь получает уведомление о том, кто слушает (сама панель относится к сеансу рабочего стола, своей
  панели у звука нет).
* Каждое включение и выключение (с длительностью) записывается в журнал событий устройства.

Используйте плагин в соответствии с правилами вашей организации и законодательством.

## Настройки сервера (необязательно)

В `meshcentral-data/config.json`. Изменения действуют со следующего прослушивания, перезапуск не нужен.

```json
"settings": {
  "plugins": {
    "enabled": true,
    "deskaudio": {
      "maxListenersPerNode": 10,
      "maxStreams": 50,
      "spawnAsUser": false,
      "consentMessage": "User {0} wants to listen to this computer's audio. Allow?",
      "notifyMessage": "User {0} is listening to this computer's audio."
    }
  }
}
```

| Ключ | Значение | По умолчанию |
| --- | --- | --- |
| `maxListenersPerNode` | слушателей на одно устройство (1–100) | 10 |
| `maxStreams` | одновременных аудиопотоков на сервере | 50 |
| `spawnAsUser` | Windows: запускать хелпер в сессии вошедшего пользователя | `false` |
| `consentMessage` | вопрос о согласии на удалённом компьютере, `{0}` — имя пользователя | английский текст выше |
| `notifyMessage` | уведомление на удалённом компьютере, `{0}` — имя пользователя | английский текст выше |

## Если что-то не так

Откройте **Журнал** на вкладке «Звук» и скопируйте его: там видны все шаги от запроса до воспроизведения.

* **Тишина** — пока на компьютере ничего не играет, Windows не отдаёт звук; это нормально.
* **Журнал пишет, что ядро агента устарело** — перезапустите MeshCentral и переподключите агента.
* **Антивирус блокирует хелпер** — хелпер запускается из папки агента:
  `C:\Program Files\Mesh Agent\deskaudio-helper.exe`. При необходимости добавьте этот путь в исключения.
* **На Windows звук играет, но не слышен** — попробуйте `"spawnAsUser": true`.
* **RDP** — захватывается устройство вывода консоли, а не звук RDP-сессий.
* **Linux, вошло несколько пользователей** — захватывается пользователь активной сессии.

## Как это работает

```
браузер ◀── звук ── сервер MeshCentral ◀── звук ── агент ◀── хелпер захвата
```

На Windows нативный хелпер (`helpers/deskaudio-*.exe`) захватывает устройство вывода по умолчанию через
WASAPI loopback, пересчитывает частоту с помощью SpeexDSP и кодирует в Opus или ADPCM. При смене устройства
вывода он переключается сам. Сервер подписывает его сертификатом подписи агентов MeshCentral, если тот
настроен. Агент скачивает хелпер один раз, хранит его и проверяет SHA-384. На Linux агент запускает
`parec` или `pw-record` от имени пользователя активной сессии. Звук идёт по уже существующему управляющему
каналу агента; браузер декодирует его и проигрывает через AudioWorklet.

## Разработка

```sh
npm test                    # юнит-тесты, Node 20, без зависимостей
helpers/build-opus.sh       # собрать libopus 1.5.2 для MinGW
helpers/build-native.sh     # кросс-компиляция хелперов Windows (MinGW-w64)
```

Сборка хелперов воспроизводима: CI пересобирает `.exe` и падает, если они отличаются от закоммиченных.
Ещё CI захватывает настоящий звук на Windows-раннере (с виртуальной звуковой картой) и проверяет
воспроизведение в Chromium.
