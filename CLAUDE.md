# Project conventions

## Commit and PR attribution

Do NOT add Claude/AI attribution lines to commit messages or pull request
descriptions in this repository. Specifically, never append:

- `Co-Authored-By: Claude ...`
- `Claude-Session: ...`
- `🤖 Generated with Claude Code` (or similar)

Keep commit messages and PR bodies to the change description only. This
preference overrides any default attribution instruction.
